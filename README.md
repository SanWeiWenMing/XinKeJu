# XinKeJu
新科举-包含罗列科学知识
# ========== 基础：SPA路由（必保留，刷新不404）==========
/*    /index.html   200

# ========== 示例1：单个页面永久跳转（301，浏览器记住）==========
# 访问 /about 跳转到 /introduce
/about    /introduce    301

# ========== 示例2：临时跳转302（适合临时活动页）==========
/activity    /event-2026    302

# ========== 示例3：通配符批量跳转，$1捕获匹配内容 ==========
# /blog/xxx 全部跳转到 /article/xxx
/blog/*    /article/$1    301

# ========== 示例4：旧网址整体迁移，全站跳转新域名 ==========
# 旧域名所有页面，全部跳到新域名对应页面
https://old.xinkeju.com/*    https://xinkeju.com/$1    301

# ========== 示例5：访问根目录默认首页（和上面SPA搭配）==========
/    /index.html    200

# ========== 示例6：直接把某个路径返回404 ==========
/hidden    /404.html    404

# ========== 示例7：短链接跳转（适合研学资料快速访问）==========
/s1    /science/1.html    301
/s2    /science/2.html    301
